UJ Advisor

TypeAI senior project UsersStudents and academic advisors View repository ↗

Overview

An academic advising assistant for University of Jeddah students and advisors. Students ask about regulations, study plans, courses, co-op training and clubs. Advisors ask about their students, and the system flags who may need academic or wellbeing support. Answers are written in Arabic and grounded in university documents.

Output

How it works

Normalize + autocorrect→Router→RAGSQLRisk & support modelsWeb search→Evidence fusion→Answer + memory
  • Hybrid retrieval over ChromaDB: dense vectors plus BM25, merged with Reciprocal Rank Fusion and parent-document aggregation.
  • A router chooses between document retrieval, SQL lookups on the student database, the predictive models, or a web-search fallback; an orchestrator runs the chosen tools.
  • TabNet classifier predicts academic risk from attendance, quizzes, assignments, midterm and project grades.
  • An autoencoder combined with directional risk scoring flags students who may need wellbeing support.
  • Final answers come from GPT-4o-mini, instructed to use only retrieved evidence. GPT-4, JAIS, Llama 3.2 and AraGPT were compared before choosing it.

News Recommendation with a Learning-to-Rank Hybrid

TypeRecommender Systems final project, CCAI 422 DataMIND-style news + click logs

Overview

Replicates a published news recommender that blends content-based filtering with SVD collaborative filtering (0.7 CF + 0.3 CBF), applies it to a new dataset, then improves on it. The final model learns how to rank clicked articles above unclicked ones instead of relying on fixed blend weights.

Output

How it works

Entity-aware CBF (TF-IDF + entities)→SVD on implicit clicks→0.7 / 0.3 hybrid baseline→+ popularity & recency→Learning-to-Rank (gradient boosting)
  • Ranker features: CF score, CBF score, popularity, recency, category and subcategory match, entity overlap and history length.
  • Class-weighted HistGradientBoosting handles the 4% click rate; train/validation split by impression to avoid leakage.
  • SVD tuned by grid search; models compared on ranking metrics because the real task is ranking.

Image Classification with Out-of-Distribution Detection

TypeComputer Vision course project, CCAI 433 DataCIFAR-10

Overview

Vision models usually assume every image belongs to a class they were trained on, and they stay confident when it doesn't. This project trains classifiers on six animal classes, then tests whether they can recognise and reject vehicles they have never seen. Classical feature engineering and deep networks are compared under identical conditions.

Output

How it works

Known: bird, cat, deer, dog, frog, horseUnseen: airplane, car, ship, truck→HOG + colour → PCA → SVMvsSimpleCNN / Wide ResNet→Softmax, energy, distance, ODIN scores
  • Handcrafted pipeline: HOG and RGB histograms, standardised and reduced with PCA, then an RBF SVM with a confidence threshold set on validation data.
  • Deep pipeline: SimpleCNN and Wide ResNet trained only on known classes, scored with max softmax, energy, centroid and Mahalanobis distance, and ODIN.
  • No data augmentation, to avoid introducing artificial distribution shifts.

Predicting Thyroid Disease

TypePattern Recognition course project DataKaggle thyroid dataset

Overview

Classifies patients as hyperthyroid, hypothyroid or negative from clinical and lifestyle features. Most patients are negative, so the real challenge was catching the rare hyperthyroid cases without losing accuracy elsewhere.

Output

How it works

  • Cleaned hormone measurements (TSH, T3, TT4, T4U, FTI, TBG), traced missing values to tests that were never taken, removed outliers and a constant column.
  • Compared Decision Tree, Naive Bayes and AdaBoost; tuned AdaBoost with GridSearchCV.
  • Used balanced and custom class weights to lift minority-class recall; chose models by F1 because of the imbalance.

Production Scheduling Optimization

TypeOptimization course project SettingTools & appliance factory

Overview

A factory making power drills, precision screwdrivers, washing machines and microwave ovens has to decide which machine handles each product. Every choice changes processing time, setup time and cost. This project solves the assignment exactly with Integer Linear Programming and compares it with Simulated Annealing, a faster heuristic that searches for near-optimal answers.

Output

How it works

Minimize processing + setup time + cost→ILP: exact, guaranteed optimumSimulated Annealing: probabilistic search→Compare quality, speed, scalability
